# LudoPaws homepage preview — authentic source and behavior

## Source of truth
- Game repository: `rekixo-lab/ludopaws`, file `android/app/src/main/java/com/rekixo/ludopaws/feature/boards/content/classic/ClassicBoardRenderer.kt`. Real classic board is a 15×15 grid; colors are red, green, yellow and blue. Its track cells and pawn overlays are generated by Android renderers.
- Official website: `rekixo-lab/ludopaws-website/assets/ludopaws-board.webp` (original Git blob `821adfa6ca1f7c4beca744ac79b2725b3baae4be`), showing the actual game board with Dog, Cat, Goat and Duck animal pawns.
- Marketing-site asset: `public/ludopaws-board.webp`, copied byte-for-byte from that official image. No external CDN or generated replacement art.
- The original image includes four player labels and the board. CSS crops the `600×813` portrait to the actual `600×600` board, retaining the center cross, color lanes and pawns.

## Interaction
- `public/index.html` uses a real button to replay a demonstration; a **separate link** goes to portfolio details. This fixes the old all-card anchor that navigated away on click.
- CSS crops animal face portraits from the original image into tiny circles, rather than inventing different character art.
- `public/rekixo-immersive.js` animates one symbolic turn at a time, in order Dog, Duck, Goat, Cat, with dice changes and hops on the correct colored board approach regions. It is **illustrative**, not generated by a match server, and does not send requests to any game API.
- Only one optional automatic demonstration runs when the card first becomes visible; replay is via click, tap, Enter or Space. No endless timer or actual match traffic.
- `prefers-reduced-motion` disables automatic playback and movement; users can click for an instantaneous position update. Animation is a progressive enhancement; without JS the original board remains visible.
- The board asset is local and small (36.9 KB). `loading="lazy"` delays the download until needed.

## Validation
- Static tests verify the copied WebP's *actual Git content hash* matches the LudoPaws original.
- Browser QA asserts the image loads, four animal sprites exist, a click changes dice and advances the Dog token, at mobile and desktop sizes.
- All prior page/theme/keyboard/overflow tests still run, with no real contact or purchase submission.
